# Create and manage discount codes — storyboard

Status: authored; audio and recording review pending.

## 01. Find the workflow

Discount codes apply supported promotional rules at checkout. Open Discounts and create a code that your team can recognize. Define the actual offer before entering values, including eligibility and usage limits.

Screen actions:

- Open `/admin/discounts`.
- Show and check **Discounts**.

## 02. Understand the controls

Choose percentage or fixed amount and enter its value. Fixed discounts need the correct currency. Configure a minimum order amount, start and end dates, total usage limit and per-customer limit when the offer requires them.

Screen actions:

- Open `/admin/discounts`.
- Select **Discount**.
- Show and check **Code**.

## 03. Perform the task

Review active state and save the discount. An active code can still be ineligible because of its dates, order amount, currency or usage rules. Test an eligible fictional checkout and an ineligible case before announcing a promotion.

Screen actions:

- Open `/admin/discounts`.
- Show and check **Discounts**.

## 04. Verify and continue

Check the accepted order total and retained discount information. Disable a code when it should no longer be offered. Do not assume that editing a promotion retroactively changes orders that have already been accepted.

Screen actions:

- Open `/admin/discounts`.
- Show and check **Discounts**.
