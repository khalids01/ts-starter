# Recording and review checklist

- [ ] Narration and UI actions reviewed against the current app.
- [ ] Isolated environment and account permissions verified.
- [ ] Fixture IDs/values prepared; no real customer, credentials or provider target.
- [ ] Walkthrough vs state-changing demonstration scope understood.
- [ ] Required ownership, outcome and cleanup checks supplied.
- [ ] All required fields and highlights visible without loading or error states.
- [ ] Audio supplied for every section.
- [ ] Every narrated action matches the corresponding footage.
- [ ] Captions retimed and reviewed against the supplied speech.
- [ ] Final video watched completely with audio.
- [ ] Exact output hashes approved in generated review.json.
- [ ] Media URLs verified and publication explicitly approved.
