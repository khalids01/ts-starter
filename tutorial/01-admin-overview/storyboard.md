# Find your way around the admin panel — storyboard

Status: authored; audio and recording review pending.

## 01. Find the workflow

Welcome. This tutorial introduces the admin panel so you can find the right place for everyday work. The menu groups related tasks together. Your account permissions determine which pages and actions are available.

Screen actions:

- Open `/admin/overview`.
- Show and check **Overview**.

## 02. Understand the controls

Overview shows a summary of the application. Expand Shop Management to find Products, Catalog, Inventory, Discounts and Images. Catalog defines how products are organized; Products contains the items you sell.

Screen actions:

- Open `/admin/overview`.
- Select **Shop Management**.
- Show and check **Products**.

## 03. Perform the task

Sales contains Orders and Customers. Delivery contains shipping methods, while Couriers contains provider connections and parcel operations. Storefront contains store settings and feedback. Analytics and Administration contain reporting and account controls.

Screen actions:

- Open `/admin/overview`.
- Select **Sales**.
- Show and check **Orders**.
- Select **Couriers**.
- Show and check **Connections**.

## 04. Verify and continue

Open Tutorials whenever you need instructions, or use the tutorial button within a page to see topics for that screen. Opening a tutorial keeps your working page in place. Choose the task you need rather than following every section at once.

Screen actions:

- Open `/admin/overview`.
- Show and check **Tutorials**.
