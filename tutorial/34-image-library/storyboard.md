# Upload, find and reuse images — storyboard

Status: authored; audio and recording review pending.

## 01. Find the workflow

The image library lets you upload and reuse assets across the admin panel. Open Images. Use files you own or have permission to publish, and keep sensitive documents out of the product image library.

Screen actions:

- Open `/admin/images`.
- Show and check **Images**.

## 02. Understand the controls

Choose Upload images and select the intended files. Check the previews and add useful tags where supported. Wait for upload success before assuming an image is available. The file server must be configured and reachable.

Screen actions:

- Open `/admin/images`.
- Select **Upload images**.
- Show and check **Upload images**.

## 03. Perform the task

Use search, filters and the table or grid view to find assets. Preview an image and copy its public URL when appropriate. Product and category image pickers can reuse library assets instead of uploading the same file repeatedly.

Screen actions:

- Open `/admin/images`.
- Show and check **Images**.

## 04. Verify and continue

Before deleting an image, check where it is used. Removing an asset can affect existing product presentation. Verify the storefront image after changing a reference, and retain the approved source file for future revisions.

Screen actions:

- Open `/admin/images`.
- Show and check **Images**.
